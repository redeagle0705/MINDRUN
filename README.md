# MINDRUN

Speedrunning 45 challenges with a simple ranking system.

A Mindustry speedrun mod: 45 short stages (Serpulo and Erekir) in a fixed order on one map. Each stage appears in place the moment the last one is cleared.

- Modes: Normal (120 s limit), Hard (165 s limit), Practice (any single stage)
- Start from **Play > MINDRUN**
- Clean runs (no skips) in Normal/Hard are submitted to the online ranking automatically
- Records and logs: `Documents/My Games/Mindustry_RUN`

## 한국어

민더스트리 스피드런 모드입니다. 한 맵에서 정해진 순서로 45개의 짧은 미션(세르폴로 + 에르키르)을 연속으로 깹니다.

- 노말(제한 120초), 하드(제한 165초), 연습 모드
- **플레이 > MINDRUN** 에서 시작
- 건너뛰기 없이 클리어하면 랭킹에 자동 등록

## Install

Mod browser: search **MINDRUN**. Or download this repository as a zip and import it in **Mods > Import**.
